- Inventory identity, authorization, private media, medicine and transcript contracts across both entry points.
- Add denied-access and record-visibility tests before merging interfaces.
- Preserve original ASR evidence and explicit confirmation.

## Verify clean-environment dependency installation
- Reproduce installation on CI Python without local caches or credentials.
- Document supported versions and review dependency-audit findings.
- Keep offline checks credential-free and live tests opt-in.

## Complete keyboard and bilingual accessibility review
- Audit worker, doctor, Dawa and map alternatives using synthetic data.
- Record reproducible keyboard/screen-reader issues and focused regression checks.
- Obtain native-speaker feedback before comprehension claims.

## Audit clinical corpus and fixture redistribution rights
- Inventory source licences, permissions and attribution for each passage/media asset.
- Replace restricted content with source links where permission is absent.
- Keep provenance and permissions separate from clinical approval.
